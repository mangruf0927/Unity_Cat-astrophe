개발 기간 : 2023.10 ~ 2023.12 (팀 프로젝트)  
개발 도구 : Unity (2021.3.24f1), C#, GitHub Desktop, Visual Studio

### [게임 개요]
Unity3D 기반의 TPS 슈팅 액션 게임으로  
작아진 주인공이 바이러스 X의 확산을 막기 위해 고양이를 추격하는 대소동을 그린 팀 프로젝트입니다.


### [실행 및 자료]
- 플레이 영상 : [YouTube](https://www.youtube.com/watch?v=XNLD89x3u7E)  
- 개발 문서 : [Google Drive](https://drive.google.com/file/d/1r8X5Gl2Zx7X5S_lwIKNB5P6A7fq9us6-/view?usp=drive_link)  


### [팀 구성 및 역할]
- 팀 구성 : 기획 3명, 개발 4명  
- 담당 업무
  - 옵저버 패턴을 적용해 UI와 로직을 분리하고 상태 변화 시 UI가 자동 갱신되도록 구현
  - 중재자 패턴을 도입해 시스템 간 복잡한 상호작용을 이벤트 기반으로 통합 관리
  - 각도 계산 기반 아이템 휠 UI를 제작해 직관적인 선택이 가능하도록 하고 인벤토리와 실시간 연동
  - 싱글톤 사운드 매니저를 적용해 씬 전환 시에도 설정을 유지하며 BGM과 효과음을 일관되게 관리
